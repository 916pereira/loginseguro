Política de Privacidade

Saiba como seus dados são utilizados neste projeto acadêmico.

1. Responsável pelo projeto

Este ambiente acadêmico é desenvolvido por João Pedro Pereira Simões. Solicitações relacionadas aos dados devem ser encaminhadas ao responsável pelo mesmo canal utilizado para disponibilizar a demonstração.

2. Dados armazenados

O sistema armazena nome, e-mail, hash da senha, perfil de acesso, status da conta e data de criação. Também registra a data do aceite, a versão dos Termos de Uso e a versão desta Política de Privacidade.

As sessões armazenam identificador, informações de autenticação e dados técnicos necessários para manter o acesso. A senha original não é armazenada.

3. Finalidades

Os dados são utilizados para criar e identificar contas, verificar credenciais, controlar permissões, manter sessões e permitir a administração do ambiente de demonstração. Não são utilizados para publicidade.

4. Armazenamento e acesso

Os dados são armazenados no MongoDB Atlas, serviço em nuvem fornecido pela MongoDB. O cluster deste projeto foi configurado na região de São Paulo. O provedor pode tratar dados técnicos conforme suas próprias condições de serviço.

Administradores e moderadores podem consultar nome, e-mail, perfil e status das contas. Apenas administradores podem modificar ou excluir usuários. O responsável pelo banco também possui acesso técnico aos dados armazenados.

5. Senhas e proteção

As senhas são protegidas com hash BCrypt. O sistema utiliza controle de acesso e proteção dos formulários contra requisições indevidas. A conexão com o Atlas utiliza TLS.

6. Cookies de sessão

Um cookie necessário ao funcionamento identifica a sessão no navegador. Ele não é usado para publicidade ou rastreamento entre sites. A sessão expira após 30 minutos sem atividade ou é encerrada ao sair da conta.

7. Conservação e exclusão

Os dados de cadastro permanecem enquanto a conta existir no ambiente acadêmico. Podem ser excluídos pelo administrador ou no encerramento do projeto. Registros técnicos e cópias eventualmente mantidos pelo provedor seguem suas condições de conservação.

8. Solicitações sobre os dados

Para solicitar informações sobre sua conta, correção ou exclusão de dados, entre em contato com o responsável. Poderá ser necessária uma verificação de identidade para proteger a conta contra solicitações de terceiros.

9. Dados de demonstração

Prefira dados fictícios durante os testes. Não informe documentos, dados financeiros, informações de saúde ou outros dados sensíveis neste sistema.
